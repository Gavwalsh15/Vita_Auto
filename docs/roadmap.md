# Roadmap

Vita Auto currently focuses on wired Android Auto. The next improvements aim to
make it easier to use, while the features below show possible future directions.
Items under consideration are not confirmed for a release yet.

## Current Focus

### Better Controller Navigation

More predictable navigation with the D-pad and analogue sticks, including moving
between items, holding a direction, selecting, and going back. The aim is to make
the physical controls a comfortable alternative to the touchscreen.

## Features Under Consideration

| Feature | What it would offer |
| --- | --- |
| Apple CarPlay | An option for iPhone users. This needs separate feasibility work before support can be promised. |
| OLED display care | Explore image movement or dimming to reduce how long static content stays on screen. Effectiveness needs testing. |
| PSP port | Explore whether the original PSP idea is feasible. hardware and USB support are major questions. |

These remain ideas, with feasibility and scope undecided.

## Have a Feature in Mind?

[Open a feature request](https://github.com/Gavwalsh15/Vita_Auto/issues/new/choose)
and describe how you would use it. If a request already exists, add your use case
there. Feedback helps decide which features are worth pursuing next.
